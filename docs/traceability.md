## Link format

```markdown
| REQ-EXEC-001 | [ADR-0002](architecture/adr-0002-manifest-dag.md) | [`DependencyGraph`](../projects/03-execution-manager/src/dependency_graph.cpp) | [cycle test](../projects/03-execution-manager/tests/dependency_graph_test.cpp) | Pass @ `0123456789abcdef0123456789abcdef01234567` | @reviewer, 2027-04-03 |
```

`Pass`에는 검증한 전체 commit SHA 또는 CI 실행 URL을 붙입니다. 상태별 필수 링크와 결과 형식은 `scripts/check_traceability.py`가 검사하고, Markdown 링크의 실제 대상은 `scripts/check_internal_links.py`가 확인합니다.
