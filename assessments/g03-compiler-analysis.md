# G3 종합 평가 — 함수 호출부터 기계어까지 추적하기

공개 입력 A·B와 다른 봉인 입력 C를 사용합니다. 공개 검사 출력만 다시 제출해서는 통과할 수 없습니다. 처음 보는 ARM 함수와 ELF, C 최적화 후보를 180분 안에 추적하고 보고 여부를 결정합니다.

## 시작 조건

- G3.1, G3.2, G3.3, G3.5 공개 A·B가 통과한 커밋이 있다.
- G3.4는 공식 Arm GNU Toolchain 14.3.Rel1 아카이브까지 검증했을 때만 완료 항목으로 채점한다.
- 평가자가 봉인 입력 C의 SHA-256, 시작 커밋, Python·Zig·GNU 상태를 기록한다.
- 인터넷, 기준 구현, 이전 답안은 보지 않는다.

## 과제 A — 새 ARM 호출 경로 설명하기 (45분, 25점)

다섯 개 이상의 정수 인자와 작은 구조체 반환을 가진 새 함수를 Cortex-M4 재배치 ELF로 만듭니다. call site와 callee에서 레지스터·stack·반환 경로를 표시하고, 어셈블리만으로 확정할 수 없는 signedness와 원본 타입은 보류합니다.

| 판정 | 점수 |
| --- | ---: |
| 대상·CPU·Thumb·AAPCS32·soft-float 기록 | 5 |
| caller와 callee를 함께 추적 | 10 |
| caller/callee-save와 stack 정렬 설명 | 5 |
| 확정할 수 없는 속성을 과장하지 않음 | 5 |

## 과제 B — AArch64 오류 주소와 소스 복원하기 (45분, 25점)

평가자가 PIE load bias, runtime 주소, 두 debug file, build ID를 제공합니다. 정확한 debug artifact만 선택하고 링크 주소를 계산한 뒤 외부 호출의 재배치, PLT, GOT, DWARF 경로를 연결합니다.

| 판정 | 점수 |
| --- | ---: |
| build ID 불일치 artifact 거부 | 5 |
| runtime·load bias·link 주소 계산 | 8 |
| section과 segment 구분 | 4 |
| relocation→PLT→GOT와 DWARF 역할 설명 | 8 |

## 과제 C — 정의된 입력의 C→IR→기계어 판정하기 (45분, 25점)

경계 검사가 있는 새 C 함수를 받습니다. 정의된 입력과 UB 입력을 먼저 나누고, Clang LLVM IR과 Cortex-M4 기계어를 생성합니다. O0·O2 결과의 동등성은 정의된 입력에서만 판정합니다.

| 판정 | 점수 |
| --- | ---: |
| source contract와 UB 경계 명시 | 7 |
| IR의 target·연산과 source 연결 | 6 |
| 정의된 입력 차등 검사가 결함을 잡음 | 8 |
| IR 모양으로 runtime을 단정하지 않음 | 4 |

## 과제 D — 비교와 보고 결정하기 (45분, 25점)

같은 Cortex-M4 계약에서 GCC와 Clang 재배치 ELF를 비교하거나, GNU 아카이브가 없으면 왜 비교를 보류했는지 resolver 출력으로 설명합니다. 이어서 양성 후보 하나와 UB·재현 실패·축소 실패·근거 부족·중복 검색 누락 대조군을 분류합니다.

| 판정 | 점수 |
| --- | ---: |
| 두 컴파일러 대상 계약이 같거나 비교를 fail-closed로 보류 | 8 |
| GCC와 LLVM 중간 표현을 혼동하지 않음 | 4 |
| 양·음성 대조군별 중단 이유가 정확함 | 8 |
| 제출하지 않은 upstream 활동을 주장하지 않음 | 5 |

## 통과 기준과 재시험

- 총점 85점 이상, 과제별 70% 이상, 즉시 불합격 0개
- 같은 시작점에서 독립 검토자가 명령과 주소 계산을 재현
- 공식 GNU 아카이브가 없으면 G3.4 점수를 다른 과제로 메우지 않고 `Provisional`로 남김

대상·ABI를 섞어 크기나 속도 순위를 만들거나, 다른 build ID로 소스 줄을 확정하거나, UB를 컴파일러 결함으로 보고하거나, 실제 제출하지 않은 upstream issue를 주장하면 즉시 불합격입니다. 7일 뒤 다른 함수·주소·경계·누락 조건을 포함한 새 봉인 입력으로 실패 영역을 재시험합니다.
