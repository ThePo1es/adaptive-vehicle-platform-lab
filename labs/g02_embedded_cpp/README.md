# G2 C++ 실습 코드와 검사기

이 폴더는 [임베디드 C++로 안전한 런타임 만들기](../../gates/g02/README.md)의 공개 검사기입니다.

| 폴더 | 역할 |
| --- | --- |
| `include/` | 학습자 코드와 검사 코드가 함께 사용하는 API |
| `starter/` | 빌드는 되지만 공개 검사는 실패하는 시작 코드 |
| `reference/` | 판정기와 결함 주입을 검증하는 기준 구현 |
| `tests/` | 공개 입력 A·B를 사용하는 독립 검사 코드 |
| `freestanding/` | 두 빌드 대상의 ELF 구조를 비교하는 최소 예제 |

학습자는 `starter/*.cpp`를 `study/g02/src`로 복사한 뒤 그 폴더의 파일만 수정합니다. 실행 명령은 [장 안내](../../gates/g02/README.md)에, API가 지켜야 할 규칙과 실패 판정은 [공통 계약](../../gates/g02/contract.md)에 정리되어 있습니다. 로컬 실행 허용 값은 자신이 작성하거나 직접 검토한 코드에만 사용합니다.

기준 구현은 학습자 프로그램에 정답을 끼워 넣기 위한 코드가 아닙니다. 공개 검사가 결함 주입본 11개를 실제로 찾아내는지 확인할 때만 사용합니다.
