# G3 컴파일 결과 분석 검사기

이 폴더는 [Arm 프로그램의 함수 호출부터 기계어까지 추적하기](../../gates/g03/README.md)의 공개 검사기입니다.

| 폴더 | 역할 |
| --- | --- |
| `starter/` | 빌드는 시작할 수 있지만 해당 실습 판정을 통과하지 못하는 코드와 답안 |
| `reference/` | 판정기와 결함 주입본을 검증하는 기준 구현 |
| `mutants/` | 호출 누락, 심벌 은닉, 경계 오류, 함수 우회, 비교 심벌 누락, 거짓 상위 프로젝트 주장을 한 결함 주입본 |
| `tests/` | 주소 복원, 정의된 입력 차등 판정, 이슈 보고 결정, CLI 흐름 검사 |

학습자는 `starter/`의 파일을 `study/g03/src`로 복사하고 그 폴더만 수정합니다. `G03_TRUSTED_LOCAL_EXECUTION=1`은 자신이 작성하거나 직접 검토한 코드에만 사용합니다. 검사기는 보안 샌드박스가 아니므로 제3자 코드는 격리된 환경에서만 컴파일합니다.

G3.1–G3.4는 Zig 0.15.2의 Clang 20.1.2로 실제 ARM ELF·LLVM IR·어셈블리를 만듭니다. G3.4는 플랫폼 명세로 고정한 공식 Arm GNU Toolchain 14.3.Rel1을 안전하게 준비한 뒤 실행하며, 아카이브가 없거나 검증에 실패하면 비교 전체가 실패합니다.
